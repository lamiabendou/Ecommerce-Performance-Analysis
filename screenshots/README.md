# Power BI Dashboard Screenshots

This folder contains screenshots of the three interactive Power BI dashboard pages developed for the E-commerce Performance & Conversion Analysis project.

## Dashboard Pages

1. **Executive Overview** — Key performance indicators, purchase value, session conversion and daily trends.
2. **Conversion & Customer Journey** — Conversion funnel, cart behavior and purchase session analysis.
3. **Product & Brand Performance** — Top-performing products, leading brands and purchase value contribution.

These screenshots provide a visual overview of the dashboard without requiring Power BI Desktop.
