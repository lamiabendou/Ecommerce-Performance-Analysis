# E-commerce Performance Analysis Report

This folder contains the final analytical report for the **E-commerce Performance & Conversion Analysis** project.

## Report Contents

The report covers:

- Project overview and objectives
- Dataset description and analytical methodology
- Executive performance analysis
- Conversion funnel and customer journey analysis
- Shopping cart abandonment analysis
- Product and brand performance
- Business insights and recommendations
- Technical implementation and project conclusions

## Key Findings

- **Total Purchase Value:** 1.21M
- **Total Sessions:** 873,960
- **Conversion Rate:** 3.36%
- **Cart Without Purchase Rate:** 89.40%
- **Top 10 Products Contribution:** 5.78%
- **Leading Identified Brand:** runail

## Technologies

Python, Pandas, Power BI and DAX.

The final report includes screenshots of the three Power BI dashboard pages and provides business recommendations based on the analysis.
